# 数据定义

票号与原始编号均为字符串，保留前导零。买家编号（buyer）为字符串，同一买家当天多票归入同一整户。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、买家、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版；切换失败（断裂更正）保留旧版继续结算并记 KEPT_PREVIOUS，断裂版本记入版本冲突；本批无基版可保留时整票阻断。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
整户返利：按买家当前生效版累计净重匹配 `rebate.tiers` 档位（min_kg 起档，per_kg 为每公斤返利CNY），应返=档位单价×累计净重，四舍五入到0.01CNY。已返=把本批被更正票回退到其 replaces 指向的上一确认版后重算的返利。本次差额=应返−已返，负值表示跌破档位应退。整户应付=票账应付−应返；整户待付=票账待付−本次差额。票账与返利账分列，已确认票金额不改写。
整户对平：户内票账 应付=已付+待付、返利账 应返=已返+差额、整户应付=票账已付−已返+整户待付，三者独立重算均成立，且户内无版本冲突、回退基准齐全。任一整户未对平则结算归档拦截。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
归档封存保存逐版证据、隔离原因、整户返利台账和原始称重字节（source.csv），非支付执行系统。数据使用虚构编号，不连接实际支付渠道。
